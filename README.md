# Amazon E-commerce ETL Data Pipeline

## 📌 Overview
**500K Rows | Data Engineer Project**

End-to-end ETL pipeline for Amazon e-commerce data. Handled 500K rows with cleaning, transformation & optimization.

## 🛠️ Tech Stack
- Python (Pandas, ETL)
- MySQL
- Indexing, JOINs, RANK, LAG, Views, Triggers

## ⚙️ Key Features
- Fixed TEXT/BLOB Error 1170
- Primary Key (AUTO_INCREMENT)
- COALESCE for NULL handling
- Indexes for performance
- Audit Log with Trigger
